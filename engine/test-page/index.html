Test Instructions

  1. Start the DAW engine: ./daw_engine --doc project.am --play
  2. Copy the token from /tmp/daw-engine-token
  3. Serve this page from a public HTTPS origin:
    • Option A - cloudflared (no account needed):
      cloudflared tunnel --url http://localhost:8080
      Download: cloudflare.com/downloads
    • Option B - GitHub Pages (3 minutes):
      Push this file to a repo, enable Pages in Settings, use the resulting URL.
  4. Open the HTTPS URL in Chrome >= 142, Firefox, and Safari
  5. Click both "Test Fetch" and "Test WebSocket"
  6. Fill in the observation report for each browser

CRITICAL: Testing from localhost or file:// will NOT trigger LNA!

ATTENTION FAUX POSITIF: Si WebSocket passe sans invite mais Fetch est bloque, c'est probablement que LNA n'est pas encore applique aux WebSockets. Le test Fetch est le canari.
